1. Pendahuluan

Sistem ini dibangun untuk memenuhi ujian CPMK-01 pada mata kuliah Pemrograman Web II. Studi kasus yang dikerjakan adalah Sistem Manajemen Transaksi Penjualan Sederhana (Paket Soal Nomor 6), yang memanajemen data pelanggan, data barang, dan data transaksi penjualan.

Teknologi yang digunakan:

  • Laravel 13.10.1 (framework PHP)
  • Blade Template (tanpa framework frontend tambahan)
  • SQLite (database)
  • Bootstrap 5 (CDN, untuk styling saja)
  • Pola MVC: Model (Eloquent), Resource Controller, Resource Route, Blade View

Sistem ini memiliki 4 tabel utama yang saling berelasi dan 3 tantangan khusus yang wajib diimplementasikan.

3. Penjelasan Fitur CRUD Dasar

3.1 CRUD Pelanggan

  • Read/Index: Menampilkan seluruh data pelanggan dalam tabel
  • Create: Form input nama pelanggan dan nomor telepon
  • Update: Form edit data pelanggan yang sudah ada
  • Delete: Hapus pelanggan dengan konfirmasi (confirm dialog)
  • Validasi: nama_pelanggan wajib diisi, no_telepon opsional

3.2 CRUD Barang

  • Read/Index: Menampilkan data barang beserta harga dan stok
  • Create: Form input nama, harga satuan, dan stok
  • Update: Form edit data barang
  • Delete: Hapus barang dengan konfirmasi
  • Validasi: semua field wajib, harga ≥ 0, stok ≥ 0

3.3 CRUD Transaksi

  • Read/Index: Menampilkan daftar transaksi beserta nama pelanggan dan total
  • Create: Form transaksi dengan pemilihan pelanggan, tanggal, dan multiple item barang
  • Detail: Menampilkan detail transaksi beserta semua item
  • Delete: Hapus transaksi dengan konfirmasi + pengembalian stok
  • Validasi: pelanggan wajib, minimal 1 item, jumlah ≥ 1

4. Penjelasan Tantangan Khusus

4.1 Perhitungan Otomatis Subtotal & Total

Subtotal dihitung di Controller pada saat menyimpan transaksi: 

$subtotal = $barang->harga_satuan * $jumlah;

Total transaksi dijumlahkan dari seluruh subtotal: 

$totalTransaksi += $subtotal;

// Disimpan ke database
Transaksi::create([
    'kode_transaksi' => 'TRX' . date('YmdHis'),
    'pelanggan_id'   => $validated['pelanggan_id'],
    'tanggal'        => $validated['tanggal'],
    'total'          => $totalTransaksi,
]);

Di tampilan form, JavaScript juga menghitung subtotal dan total secara real-time saat pengguna memilih barang atau mengubah jumlah.

4.2 Validasi Stok Tidak Boleh Minus

Sebelum menyimpan, sistem mengecek apakah jumlah beli melebihi stok: 

if ($jumlah > $barang->stok) {
    return back()->withInput()
        ->with('error', "Stok barang \"{$barang->nama_barang}\" tidak mencukupi. Stok tersisa: {$barang->stok}.");
}

Setelah transaksi tersimpan, stok barang dikurangi otomatis: 

$barang->decrement('stok', $item['jumlah']);

Jika transaksi dihapus, stok dikembalikan: 

$barang->increment('stok', $detail->jumlah);

4.3 Rekap Penjualan Per Hari

Menggunakan query grouping dengan aggregate function: 

$rekap = Transaksi::select(
        'tanggal',
        DB::raw('COUNT(*) as jumlah_transaksi'),
        DB::raw('SUM(total) as total_penjualan')
    )
    ->groupBy('tanggal')
    ->orderBy('tanggal', 'desc')
    ->get();

5.2 Transaksi Controller — Metode store()

public function store(Request $request)
{
    $validated = $request->validate([
        'pelanggan_id'      => 'required|exists:pelanggan,id',
        'tanggal'           => 'required|date',
        'item_barang_id'    => 'required|array|min:1',
        'item_barang_id.*'  => 'required|exists:barang,id',
        'item_jumlah.*'     => 'required|integer|min:1',
    ]);

    $totalTransaksi = 0;
    $detailItems    = [];

    for ($i = 0; $i < count($validated['item_barang_id']); $i++) {
        $barang = Barang::find($validated['item_barang_id'][$i]);
        $jumlah = $validated['item_jumlah'][$i];

        // Validasi stok
        if ($jumlah > $barang->stok) {
            return back()->withInput()
                ->with('error', "Stok barang \"{$barang->nama_barang}\" tidak mencukupi.");
        }

        $subtotal = $barang->harga_satuan * $jumlah;
        $detailItems[] = [
            'barang_id' => $barang->id,
            'jumlah'    => $jumlah,
            'subtotal'  => $subtotal,
        ];
        $totalTransaksi += $subtotal;
    }

    DB::transaction(function () use ($validated, $detailItems, $totalTransaksi) {
        $transaksi = Transaksi::create([
            'kode_transaksi' => 'TRX' . date('YmdHis'),
            'pelanggan_id'   => $validated['pelanggan_id'],
            'tanggal'        => $validated['tanggal'],
            'total'          => $totalTransaksi,
        ]);

        foreach ($detailItems as $item) {
            DetailTransaksi::create([
                'transaksi_id' => $transaksi->id,
                'barang_id'    => $item['barang_id'],
                'jumlah'       => $item['jumlah'],
                'subtotal'     => $item['subtotal'],
            ]);
            Barang::find($item['barang_id'])->decrement('stok', $item['jumlah']);
        }
    });

    return redirect()->route('transaksi.index')
                     ->with('success', 'Transaksi berhasil disimpan.');
}

5.3 Model Transaksi (app/Models/Transaksi.php)

class Transaksi extends Model
{
    protected $table = 'transaksi';
    protected $fillable = ['kode_transaksi', 'pelanggan_id', 'tanggal', 'total'];

    public function pelanggan()
    {
        return $this->belongsTo(Pelanggan::class);
    }

    public function detailTransaksi()
    {
        return $this->hasMany(DetailTransaksi::class);
    }
}
